# 参考资料

本目录保留了 PAJ7620 参考代码、第三方许可文本和项目自己的接线/音频参考资料说明。

Tang Nano 20K 官方资料请从 [Sipeed 官方页面](https://wiki.sipeed.com/hardware/en/tang/tang-nano-20k/nano-20k.html) 获取。PAJ7620 参考库来源见根目录的 `THIRD_PARTY_NOTICES.md`。

`src/board_a/aux_program.v` 中的历史注释写作 `paj7620.h`，仓库实际保留的对应文件名是 `vendor_paj7620.h`；这只是资料文件名映射，不影响 FPGA 工程编译。
