# OLED 同源真实波形版 v25

这版把上位机原来的“音符驱动律动动画”改成实际音频采样波形。A 板读取最终混音、总音量处理后的音频，和送往功放及 C 板 OLED 的 I2S 来自同一信号。沿用 OLED WAVE 的正向过零触发、四点平均降采样、256 点采集与八位归一化方法，传输其中前 128 点用于波形显示。

电脑按每帧峰值自动放大，波形上下总高度约占绘图区的 88%，不改变声音大小或合成音色。OLED 与电脑分别触发采集，刷新时刻不同，因此多音叠加时两边图形不保证逐帧一致。

## 如何使用

1. 关闭旧上位机。
2. 仅给 A 板烧录 program/A_waveform_v25.fs，操作方法与此前相同。不要把它烧到 B/C 板。
3. B 板、C 板、ESP32 保持原来的程序与接线，不需要重新烧录。
4. 双击根目录 start_host.bat，选择此前正常工作的电脑 USB-TTL 端口并连接（115200）。电脑仍使用 RXD→A52、TXD→A86；ESP32 仍使用 A76/A80。
5. 按住铜箔，区域标题应变成“实际音频波形 · OLED同源 · 显示自动放大”。正弦音色应呈正弦形，其他音色与和弦按真实合成结果变化。

旧 A 板固件没有波形数据，新上位机会显示“等待A板波形数据”，不会再用动画冒充实际波形。未收到有效采样超过 0.6 秒时清除旧图。

这次显示的是 OLED 的 WAVE 时域波形；不随 C 板按键切换成 XY、七音柱或频谱。原有 OLED 功能完全保留。

## 保留功能

五种音色、多键演奏、压力、编码器、手势、存储、电脑/手机双端控制、LED 和 OLED 保留。蓝牙串口数据格式未改变，波形扩展仅发送给电脑端。旧版文件夹完全保留。

## 传输与验证

- PC 新增 AA5A 140 字节波形帧，与 AA59 状态帧交错发送，不打断单个数据包。
- 采样率 52734.375 Hz，四点平均后为 13183.59375 Hz。显示窗口约 9.71 ms；按键数量不会人为改变波形高度。
- 每次波形传送约 12.2 ms，整体刷新约 7 次/秒。电脑显示刷新不等于音频演奏延迟；FPGA 音频通路未插入等待。
- 采样只做可视化，不播放录音，不在电脑合成声音。
- 通过 HDL 仿真、Python 协议测试与界面布局检查。validation 截图使用模拟输入，不代表已连接实物。

完整源代码在 src，A 板工程为 projects/A/board_a.gprj。可执行 python build.py A --synthesize --hardware 重新编译。
