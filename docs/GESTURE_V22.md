# v22 手势响应优化：先看这里

在v21竹笛完整工程上，仅修改A板手势事件过滤。接线、手势映射、五种音色、七键和弦、OLED、LED、压力、编码器和存储功能不变。旧版文件均保留。

## 下载哪个

只更新A板：`program/A_GESTURE_V22.fs`。若B/C已经烧v21，无需重新下载；完整包仍附原封不动的B/C v21程序。不要改现有接线。ESP32固件、电脑上位机、手机界面也不需要因为本次修改再次更新，继续用v21即可。

## 改了什么

原来识别一次后统一屏蔽400ms。现在第一下立即接收，换方向的两次有效事件只需相隔约60ms；同方向再次触发至少相隔180ms，并需要先读到持续约40ms的无手势状态。持续读到同一个手势不会因时间到而重复执行。多方向混合结果不当作有效命令，也不再抢占有效手势的等待时间。

这些时间是FPGA事件过滤参数，不是保证传感器能识别每秒多少次动作，也不是手势总延迟。I2C读取、传感器内部识别和手机刷新仍需要时间。模块光学参数、初始化寄存器和读取速度没有更改。

| 动作 | 保留的功能 |
|---|---|
| 右挥 | 下一种音色，五种循环 |
| 左挥 | 上一种音色，五种循环 |
| 上挥 | 开启编码器颤音 |
| 下挥 | 关闭编码器颤音 |

前后移动、画圈仍未绑定指令。先在电脑或手机打开“手势切换”开关，否则模块识别到也不会执行上述操作。

## 实物验证

1. 按原成功流程下载新的A板程序。音量先放一半，确认触摸发声正常。
2. 打开手势功能，传感器正面无遮挡，手掌先在约5～15cm范围内测试。
3. 单次右挥，应只切一次音色；手放住不应一直切换。
4. 右挥后左挥，先按约200～300ms间隔测试，比较旧版是否更容易连续响应。
5. 同方向再次挥动前，先离开感应区再回来；上挥、下挥分别核对颤音开关。
6. 关闭手势功能，再挥手应不改变音色和颤音开关。

界面手势名称仍保留最后一次结果，连续做相同手势时文字可能不变化，要看音色/颤音功能是否真的执行。若动作仍漏识别，先记录“界面有没有识别方向、功能有没有执行”两点；实机灵敏度仍需结合安装距离和环境调试。

## 数字验证

新增过滤器验证60ms换向保护、180ms同向保护、40ms无手势重置、持续结果及短空白抖动抑制、混合结果、重试复位。PAJ数字I2C模型验证读取及持续手势，A板顶层验证左右上下动作和功能关闭。编译及其他回归记录见VALIDATION.md；未进行硬件烧录或光学识别实测。
