# 三板互连与 C 板外围接线

这里的 A/B/C 表示板卡角色，数字对应工程 CST 中的 FPGA 封装管脚号，并非从排针一端开始数的位置。请与 Tang Nano 20K 官方引脚图一起核对，A 板各传感器与电源的完整说明见根目录 `A_WIRING.md`。

## A 到 B/C 的控制与音频链路

| A 板 | B 板 | C 板 | 作用 |
|---|---|---|---|
| A77 | B27 | C27 | 控制串行时钟 |
| A85 | B28 | C28 | 控制串行数据 |
| A49 | B26 | C26 | 控制片选 |
| A16 | B25 | C25 | 采样帧同步 |
| A17 | B73 | C73 | 合成结果回传时钟 |
| A20 | B29 | C29 | 合成结果回传片选 |
| A42 | B30 | 不接此线 | B 板合成结果返回 A |
| A41 | 不接此线 | C30 | C 板合成结果返回 A |
| GND | GND | GND | 公共参考地 |

B30 和 C30 是两个独立输出，不要互接。三板不需要额外高速收发器，短距离通过 3.3V GPIO 串行传输；线应尽量短并保持共地。

## A 板最终 I2S 与 C 板监视

| A 板 | MAX98357A | C 板 |
|---|---|---|
| A73 | BCLK | C48 |
| A74 | LRC / LRCLK | C31 |
| A75 | DIN | C41 |

MAX98357A VIN 使用已调为 5V 的外部稳压电源，所有 GND 共地，扬声器只接 SPK+ 与 SPK-。扬声器任一端不要接公共地。SD_MODE/GAIN 保留已验证的模块配置。

## OLED 与七音 LED

OLED 的 VCC 接 C 板 3.3V，GND 接公共地，SCL 接 C71，SDA 接 C72。显示切换键接 C42 与 GND，低电平有效。当前 LED 显示按音反馈，C86 历史指引键不代表已经实现下一音曲谱教学。

| 音 | C 板 LED 输出 |
|---|---|
| Do | C51 |
| Re | C53 |
| Mi | C74 |
| Fa | C75 |
| Sol | C77 |
| La | C80 |
| Si | C85 |

每个输出串接一只 330Ω～1kΩ 限流电阻，再接普通 LED 阳极，阴极接 GND。电阻可位于 LED 前或后，不能省略。不要直接用 FPGA 引脚驱动灯带或大功率灯。

## 供电原则

三块开发板及模块 GND 相连。三板各自 3.3V 稳压输出不并联：A 的传感器用 A 的 3.3V，C 的 OLED 用 C 的 3.3V。外部功放 5V 不能直接回灌正在由电脑 USB 供电的开发板。12V 只进入 LM2596 输入端，接模块前先测量输出为 5V。

编码器工程输入为 A25/A56。历史调试口述曾出现 A26，重新制作时以 `projects/A/pins.cst` 与实际官方引脚图确认；不要仅凭历史口述改动已正常工作的接线。
