# v22：手势响应优化

本包最新说明是 [GESTURE_V22.md](GESTURE_V22.md)。已有v21只需更新A板 `program/A_GESTURE_V22.fs`，B/C、电脑、手机和ESP32继续沿用v21。以下保留v21首次安装说明，A板文件名以本段为准。

第五种音色由小提琴改为竹笛。旧版工程保留，现有接线不用调整。

## 1. 下载三块板程序

| 板 | program 内文件 |
|---|---|
| A | A_GESTURE_V22.fs |
| B | B_CELLO_FLUTE_V21.fs |
| C | C_CELLO_FLUTE_OLED_V21.fs |

按之前成功的流程分别选中对应板下载。若A板已烧v20，A的逻辑没有变化，可以保留；B和C必须同时更新成v21。为方便完整交付，本包也提供重新编译的A板程序。第一次可用SRAM验证，断电保存用之前成功的Flash下载流程。

## 2. 电脑上位机

关闭旧版，双击本文件夹 `start_host.bat`。标题应显示“七音竹笛 v21”。音色为正弦、锯齿、方波、大提琴32、空灵竹笛32。实体音色键和手势也按五种循环。

电脑单独串口：USB-TTL RXD接A52，TXD接A86，GND共地，VCC不接，3.3V逻辑。

## 3. 手机APP控制页

新版入口为 `mobile/index.html`，必须同时使用同文件夹的 `app.js`、`protocol.js`、`styles.css`，不能只复制HTML。把这四个文件替换到你原先手机访问的网站目录，再用原来能连蓝牙的浏览器打开。详细说明见 `mobile/README.md`。

手机原来已打开的页面不会自行升级，需重新加载；若仍只有四个音色，说明仍是旧缓存或旧网址。iPhone Safari不提供Web Bluetooth，继续使用你之前已经连接成功的兼容蓝牙浏览器。本包是网页控制端更新，没有自动发布网站。

ESP32-C3继续用原固件即可：BLE UUID、108字节状态帧长度、命令格式和串口速率未变，新增音色值4由桥接固件原样透传。本包附源码备查，未在本机编译ESP固件。

手机与电脑可以同时控制：A76接ESP GPIO5；ESP GPIO4接A80；电脑使用A52/A86，两路接收分开。公共GND相连，USB-TTL TXD不能再与ESP GPIO4共同接A80。双方控制同一套参数，以FPGA最新状态回报为准。

## 4. 竹笛应该是什么效果

基音突出，高次谐波较弱，柔和起音和尾音，混入轻微滤波气息声；保持C4～B4音域，支持多键和弦、压力、电位器、编码器颤音。大提琴仍低一个八度，其余三个音色保留。它是实时合成的竹笛近似，最终听感需要实物试听，没有新增混响。

“32”仍指每音32谐波，七键共224个合成分量，并非32个独立音符复音。B计算1～16谐波，C计算17～32谐波。竹笛与大提琴复用引擎。

## 5. 验收顺序

1. 更新B/C，启动新版电脑端及新版手机页面，先把音量放在一半。
2. 选空灵竹笛，按Do、Mi、Sol，再同时按三键；松开Mi，Do/Sol应继续。
3. 依次试七键，确认LED、OLED和电脑/手机按键状态都对应。
4. 从手机切换竹笛，电脑应显示竹笛；再从电脑切换大提琴，手机应同步显示。
5. 检查压力开关、旋转编码器颤音、手势和原有旋钮。
6. 在准备好的录制区录一段竹笛和弦，停止并等待收尾后重演。

旧录音中的音色4现在按竹笛演奏，音色0～3含义不变。存储沿用v19/v20的按需擦除、STOP收尾与故障处理。电脑串口显示具体故障码；手机串口仅提示通用存储故障时，应到电脑端查看细节。

编译、数字验证和资源见 `VALIDATION.md`。本次未自动烧录任何板卡。
